How to run the scripts of this folder again (11.11.26, analyst "stop_and_centring").

Python: D:/AI_Project/.venv/Scripts/python.exe, with this folder as the working directory. Nothing connects to the
robot; pictures, logged joints and saved model answers are only read; every result is written into this folder.

  1. python camera_shift.py robot_test       (then: before_move, after_move)   about 1 minute each
        writes camera_shift.json (the picture shift and roll of the camera per period); printed: camera_shift_<period>.out.txt
  2. python measure_check.py                                                    about 2 minutes
        printed: measure_check.out.txt; pictures: overlays_robot_runs.png, overlays_demonstrations.png
  3. python robot_runs.py                                                       about 1.5 minutes
        robot_runs_steps.csv, robot_runs_ends.csv, robot_runs_maps.png, robot_runs_offsets.png, robot_runs_ends.png
  4. python demonstration_ends.py 1 3        (then: 4 6)                        about 2.5 minutes each
        demonstration_ends_<first>_<last>.csv, demonstration_last_steps_<first>_<last>.csv
  5. python demonstration_centring.py 1      (then: 2, 3, 4, 5, 6)              0.5 to 2 minutes each
        demonstration_centring_<sheet>.csv
  6. python stop_labels.py                                                      a few seconds
        printed: stop_labels.out.txt; picture: stop_probability_by_shortfall.png
  7. python summary.py                                                          a few seconds
        printed: summary.out.txt; pictures: ends_scatter.png, centring_distribution.png

The printed output of each run was kept as <script or part>.out.txt. picture_measures.py and run_measures.py hold the
measures themselves and are imported by the scripts.
